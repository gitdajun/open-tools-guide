# Excalidraw

手绘风格白板，适合流程图、架构图、简单原型。

- 仓库：https://github.com/excalidraw/excalidraw
- 公共站点：https://excalidraw.com

## 直接使用

打开 https://excalidraw.com 即可画，可导出 PNG / SVG / 源文件。

## 本地运行（开发）

```bash
git clone https://github.com/excalidraw/excalidraw.git
cd excalidraw
yarn
yarn start
```

生产自托管可参考官方 Docker / 静态构建文档。

## 小技巧

- 支持协作房间（视部署方式）
- 库与组件可保存复用
- 导出源文件便于版本管理
