# Godot

开源 2D / 3D 游戏引擎（MIT）。

- 仓库：https://github.com/godotengine/godot
- 下载：https://godotengine.org/download

## 安装

1. 打开官网下载页，选择系统与版本（稳定版即可）
2. 解压后运行编辑器（通常免安装）
3. 新建项目，选择 2D 或 3D

## 入门路径

- 熟悉场景树、节点、信号
- 脚本默认使用 GDScript（也支持 C# 等）
- 官方文档与入门教程：https://docs.godotengine.org

## 导出

在「导出」中配置各平台模板，可打出 Windows / macOS / Linux / 移动端等包（需下载对应导出模板）。
